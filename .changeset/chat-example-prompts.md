A new chat offers example prompts above the message box, such as "Plan a three-day trip to Lisbon on a budget", picked at random each visit, with More ideas to see others. Picking one drafts it into the message box so you can edit it before sending; nothing is sent until you send it. The examples hide while you type and come back if you clear the box.
